# 口播音频提示词细则

## 「音频提示词」在本项目里就是配音文本本身

本项目不使用音频生成模型（如文生音效），口播音轨由 **TTS** 合成，因此音频侧的可控项只有：

| 可控项 | 由谁决定 | 说明 |
|---|---|---|
| 文本本身 | 你（Agent） | 断句、标点、数字写法 |
| 语速倍率 | 项目设置 | 默认 **1.1 倍**，全局统一，你不写进文本 |
| 音色编号 | 项目设置 | 豆包 `speaker` / MiniMax `voice_id` |
| 逐句时长 | TTS 实测 | 决定每个镜头的画面时长 |

结论：**你要做的只有一件事——写出念得准、断得对的文本**。

## 断句规则

1. 一句一镜：`shot_plan` 给你的句子就是这一镜的全部旁白，不要跨镜合并
2. 句末用「。」；需要短停用「，」；并列项用「、」
3. 长句（>30 字）必须拆成两句 → 同时也就多一个镜头，回去让稿子本身更短句
4. 不要用省略号「……」代替停顿（TTS 处理不一致），直接断句

## 数字与专有名词

| 写法 | 问题 | 改法 |
|---|---|---|
| 30% | 可能读成「三十百分号」 | 三成 |
| 1200 万 | 可能读成「一千二百零万」 | 一千两百万 |
| 2024 年 | 一般可读，但 2024 可能读成「两千零二十四」 | 二零二四年 |
| GPT-4o | 英文缩写读法不定 | 写成「G P T 4 O」或改口语说法 |
| 《红楼梦》 | 书名号一般不读，安全 | 保留 |

## 情绪与重音

TTS 只对文本敏感，不认「（激动）」「**重读**」这类标记（会被念出来）。要表达情绪：

- 用词本身带情绪：把「这个数字很大」写成「这个数字，大得离谱」
- 用短句 + 逗号制造节奏：短句急促、长句平稳
- 需要强调的词放在句首或句尾（口语里这两处天然重读）
- 需要明显停顿 → 拆句，而不是加符号

## 常见翻车点清单

- ❌ 文本里混入 markdown（`**`、`#`、`-`）→ 会被念出来
- ❌ 中英文混排没有空格 → 英文单词与汉字粘连，读音节奏错乱
- ❌ 括号注释（「（笑）」「（停顿两秒）」）→ 会被念出来
- ❌ 全角空格、不间断空格 → 部分 TTS 会读成停顿或直接吞掉
- ❌ 同一镜头里塞两句 → 音频时长与画面时长错位（这是音画不同步的头号原因）

## 交付与自检

保存前检查每个 `narration_text`：

1. 与 `shot_plan` 的对应句子**逐字一致**
2. 不含 markdown、括号注释、语速说明
3. 朗读一遍不拗口；数字已口语化
4. 字数与 `shot_plan` 的 `char_count` 一致（差 1~2 字可以接受，差 5 字以上必须改回）

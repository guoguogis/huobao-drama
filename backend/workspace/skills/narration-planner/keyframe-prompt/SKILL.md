# 关键帧图像提示词细则

## 一张好关键帧 = 一个视觉命题

口播视频的镜头多为 3~8 秒，观众只来得及读一个信息。所以每张关键帧：

- 只保留**一个主要视觉命题**（一个主体在做一件事）
- 但画面不能空：至少包含 **主焦点 / 信息支撑层 / 环境层** 三层
- 不要靠堆无关物体制造"丰富"——多余的物件会抢走注意力

## 分层写法（推荐顺序）

写成一段连贯描述，内部隐含下面四层：

1. **主焦点**：主体 + 动作 + 朝向（占画面 1/3 以上）
2. **信息支撑层**：与该镜头论点直接相关的物件、图表、道具（可有 1~3 个）
3. **环境层**：地点、时段、天气、背景剪影
4. **前景/纸边层**：拼贴风格下的纸片边缘、撕纸痕、投影、前景遮挡物

## 风格取向（与项目风格预设对齐）

口播视频常用「纸片拼贴 / 编辑插画」风格，写作时可用这类关键词强化统一性：

- 材质：纸张颗粒、半色调网点、剪纸边缘、纸片投影、手撕边
- 构图：拼贴层叠、杂志剪报、扁平视角、微立体投影
- 调色：有限调色板（2~4 色）、高对比、暖冷分区

**风格词由项目风格预设统一注入**，不要自创风格体系，也不要写具体品牌/艺术家名字。

## 画面内文字

- 尽量不放文字；必须放时只允许**少量准确汉字**（地名、年代、一个短判断）
- 不要在画面里生成句子、段落、乱码文字
- 需要长文案时，把它留到后期字幕，不要写进关键帧

## 相邻镜头的连续性检查表

生成前自查（不通过就改）：

- [ ] 与前一镜头至少共享一个视觉锚点（主体/空间/色调）
- [ ] 与后一镜头之间是"可控推进"，不是跳到无关场景
- [ ] 两帧差异足以让首尾帧动画有变化（不是几乎相同的两张图）
- [ ] 主体在画面中的位置允许动画平滑过渡（不要在完全相反的位置）

## 反面例子

- ❌「镜头1：画面中出现一个人，背景是城市，有文字写着今天讲三个要点」——元话语 + 大段文字
- ❌「一个非常精美、细节丰富、超高清的宏大场景」——空泛形容词，没有可执行信息
- ❌「与上一张完全相同的场景，但更亮一点」——首尾帧动画会看不出变化

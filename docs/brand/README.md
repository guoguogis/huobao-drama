# 剧威视频创作平台 · 品牌标记

## 概念：胶片即播放键

一个轮廓，两个含义——**竖条是胶片，右侧是播放三角**。它们不是两个元素拼在一起，而是**同一个连续实心形状**；左侧三个齿孔是真实镂空，透出底部渐变。

命名关联：「剧」= 剧幕 / 剧本 → 胶片条；「威」= 锋芒 / 推进感 → 朝右锐角的播放三角。

## 为什么这样设计（可记忆性论证）

1. **单一轮廓**——能凭记忆一笔画出。这是"容易被记住"的第一条件；多元素徽标在 16px 会互相干扰、糊成一团。
2. **只有一处转折**——从竖条到斜边仅一次方向变化。轮廓越简单，小尺寸识别率越高。
3. **双关语义**——胶片（创作）与播放（成片）压缩进同一形状，不需要文字就说明产品做什么。
4. **与旧标彻底切割**——旧标是"暗底 + 发光火焰球 + 光圈"，新标是"亮橙 + 扁平 + 胶片三角"。并排不会混淆。
5. **色彩承接品牌**——沿用 `--accent` 橙族（`#ea580c` → `#fbbf24`），与主按钮渐变同族，界面里天然协调。

## 设计过程（三个方向、三轮评审）

| 方向 | 结论 |
|---|---|
| 光圈播放（白色圆盘 + 橙色三角 + 叶片缝） | **淘汰**：叶片刻痕在小尺寸像饼图，16px 糊成一团 |
| 剧幕折角（竖版剧本页 + 右上折角 + 播放三角） | **淘汰**：语义不错（剧本→视频），但 16px 退化成"白块 + 橙点"，且"文档 + 播放"过于通用 |
| **胶片三角（胜出）** | 单一轮廓、16px 仍可辨、与旧标零相似度 |

胜出方向的后续取舍：

- **加宽胶片条 + 加大齿孔** → 提升 32px 下的可辨性
- **齿孔改为真实镂空（mask）** → 避免硬编码颜色与底部渐变对不上
- **淘汰"尖端斜切"变体** → 小尺寸读成"缺了一块"，不增语义
- **淘汰"边缘齿形轮廓"变体** → 读成皇冠 / 咬痕，丢失胶片语义

## 栅格验证

已在 **200 / 64 / 32 / 16px** 及浅底、深底、界面侧栏 40px 场景逐级渲染确认：16px 时齿孔并入轮廓，但仍保留"带缺口的三角形"这一可辨特征。

## 规范

| 项 | 值 |
|---|---|
| 瓦片圆角 | 116 / 512 ≈ 22.6%（iOS squircle 观感） |
| 渐变 | `#ea580c`（左上）→ `#fbbf24`（右下） |
| 标记 | `#FFFFFF` |
| 安全边距 | 四周 ≥ 瓦片边长的 1/8 |
| 最小尺寸 | 瓦片版 16px；单独使用标记时 ≥ 24px |
| 单色 | 浅底用 `#ea580c`，深底用 `#fbbf24` |
| 桌面图标 | **满幅方图**，圆角交给系统蒙版（不要预先切圆角） |

**禁止**：拉伸变形、加描边、加投影、旋转、改变渐变方向、把胶片与三角拆成两个元素、把齿孔做成实心点。

## 重新生成

```bash
cd backend && node scripts/build-brand-assets.mjs
```

- 依赖仅 `sharp`（backend 已装）；ICO / ICNS 容器按规范手写，不引入额外依赖
- 幂等覆盖上表全部文件，并自检容器结构（内嵌 PNG 签名、偏移、总长）与回读尺寸
- 改颜色 / 圆角 / 齿孔：编辑脚本顶部的 `GRADIENT`、`TILE_RADIUS`、`HOLES` 常量

## 1. Cline

- **定位**: VSCode/JetBrains 扩展 + 桌面 App + CLI + SDK + Kanban 的多形态自主编码 agent，Apache-2.0 开源，agent core 已抽成 `@cline/sdk`。
- **核心架构/形态**: 扩展（VSCode / JetBrains）、桌面 app（macOS/Win/Linux）、CLI（`npm i -g c`）、SDK（`npm install @cline/sdk`，需 Node 22+）、Kanban 看板、TUI。语言 TypeScript。**License = Apache-2.0**。**stars 69,213**（观测 2026-09-24）、forks 7,507、open issues 1,432、archived=false。[来源](https://api.github.com/repos/cline/cline) [来源](https://docs.cline.bot/cline-overview) [来源](https://docs.cline.bot/sdk/overview)
  - 版本现状（2026-09-24）：`desktop-v0.0.35`（2026-09-24 发布）、`cli-v3.0.64`（2026-09-22）、`sdk/sdk/v0.0.86`（2026-09-24）。**没有 4.x；CLI 主线是 3.x**。[来源](https://api.github.com/repos/cline/cline/releases/latest) [来源](https://api.github.com/repos/cline/cline/releases?per_page=12)
- **支持的模型**: 三条路径——① **Cline (usage-billing)** 即 BYO-credit，一次登录用 100+ 模型，可充 Cline credits，按量付费；② **ClinePass** 订阅；③ **完全 BYO-key**（云厂商或本地 runtime）。模型目录规模：**209 个 provider / 6,386 个模型**（2026-09-24 版本说明）。企业版明确支持 AWS Bedrock / Google Vertex AI / Azure OpenAI / Anthropic / OpenAI / Cerebras / 任意 OpenAI 兼容端点。本地模型走 Ollama / LM Studio / llama.cpp / LiteLLM。[来源](https://docs.cline.bot/getting-started/cline-provider) [来源](https://docs.cline.bot/sdk/overview) [来源](https://docs.cline.bot/enterprise-solutions/overview)
- **关键差异能力**: Plan/Act 双模式；**shadow-git checkpoints**（独立于项目 git 的影子仓库，每次工具调用后提交快照，可 Restore Files / Restore Task Only，默认开启）；MCP 市场；`.cline/rules` + Skills + Plugins + Hooks；Memory Bank。2026 年新架构为 SDK-backed，**已弃用 `Focus Chain` 与 `Explain Changes`**，`.clineignore` 也在弃用中（官方承认它「从来不是安全边界」）。[来源](https://docs.cline.bot/core-workflows/checkpoints) [来源](https://docs.cline.bot/resources/deprecations)
- **并行多 agent / git worktree / 云端沙箱后台任务**:
  - **Subagents**（实验特性，默认开启）：并行只读研究 agent，各自独立 context window 与 token 预算，只读工具（read_file / list_files / search_files / list_code_definition_names / 只读 execute_command），**不能编辑文件、不能用浏览器、不能访问 MCP、不能再 spawn**。跨 VSCode/JetBrains/CLI 生效。[来源](https://docs.cline.bot/features/subagents)
  - **Agent Teams**（`cline --team-name auth-sprint "..."`）：协调者 agent 通过**共享 task board** 分派子任务，团队状态跨 session 持久化。**仅 SDK / CLI / Kanban 支持，VSCode 与 JetBrains 扩展不支持**。[来源](https://docs.cline.bot/cli/agent-teams)
  - **git worktree 隔离**：桌面版欢迎页 "Work in" 可选 Local 或 **Worktree**，会从当前分支切出 `cline/<id>` 分支、在 `~/.cline/worktrees/` 建 worktree 并在其中运行，**不碰你的工作树**；删除任务会连 worktree 与分支一起删（含未提交改动）。[来源](https://api.github.com/repos/cline/cline/releases?per_page=12)
  - **Kanban**（research preview）：`npx kanban`，每张卡片获得**独立 git worktree + 终端**，可多 agent 并行；支持 Commit / Open PR。[来源](https://docs.cline.bot/usage/kanban)
  - 云端沙箱后台任务：desktop 有 Cloud 会话开关，但**沙箱容器化细节未核实**。CLI 有 `cline history --json` 等无头自动化。[来源](https://api.github.com/repos/cline/cline/releases?per_page=12)
- **定价档位**（**来源日期 2026-08-29**，CostBench 独立交叉核对官方定价页）: 开源版 **Free**；**Teams $20/月**；**Enterprise 定制 / 联系销售**。[来源](https://costbench.com/verify/cline/) 官方另有 **ClinePass $9.99/月**，官方口径为「相比标准 API 费率，在热门开源编码模型上提供 2-5 倍用量」。[来源](https://docs.cline.bot/getting-started/clinepass) 官方定价页 `https://cline.bot/pricing` 为客户端渲染，纯文本抓取拿不到具体数字 —— 该页 URL 已实抓但**未渲染出金额**。[来源](https://cline.bot/pricing)
- **企业/私有化**: 官方口径「**代码永不离开你的环境；不索引、不上传、不训练**」（client-side execution）。BYO-inference（用自己的云合同与谈定价，Cline 不加价）。**SSO via WorkOS**，支持 Okta / Azure AD / Google Workspace / 任意 SAML-OIDC，**JIT 自动 provision**，角色从 IdP 同步（Admin/Owner→Admin，Member→Member），撤销用户由 IdP 统一处理。**三层 RBAC（Member/Admin/Owner）**，权限矩阵覆盖邀请/改角色/移除/配置 provider/账单。**OpenTelemetry 导出**到 Datadog/Grafana/Splunk，含成本分解；管理操作有**选择性审计日志**。模型与工具可按团队管控，支持远程集中配置。部署方式为「连接到你自己的基础设施」，**air-gapped 专门说明未核实**。[来源](https://docs.cline.bot/enterprise-solutions/overview) [来源](https://docs.cline.bot/enterprise-solutions/onboarding) [来源](https://docs.cline.bot/enterprise-solutions/team-management/managing-members)
- **已知短板**（有来源的批评）:
  - **token 成本高**：仓库 issue 标题「High Token Costs in Cline: Lack of LSP Integration Leads to Excessive File Operations」指出缺少 LSP 集成导致过度文件操作。[来源](https://github.com/cline/cline/issues/8336)
  - **OpenRouter 集成缺 provider pinning，成本被抬高 3-5 倍**。[来源](https://github.com/cline/cline/issues/10596)
  - checkpoints 在超大仓库会占大量存储并拖慢 Cline（官方文档自述）。[来源](https://docs.cline.bot/core-workflows/checkpoints)
  - Subagents 与 Kanban 均为实验/research preview，行为可能变。[来源](https://docs.cline.bot/features/subagents) [来源](https://docs.cline.bot/usage/kanban)

  - **维护状态（关键）**：仓库自 2026-05-15 起只读。最后 push 2026-05-15T18:08:47Z。最终 release **v3.54.0**（2026-05-15T17:52:24Z）。最后三条提交即关停动作：`Release v3.54.0` → `Redirect roocode.com to roomote.dev (#12374)` → `Remove roocode.com web app (#12375)`。[来源](https://api.github.com/repos/RooCodeInc/Roo-Code/releases/latest) [来源](https://api.github.com/repos/RooCodeInc/Roo-Code/commits?per_page=3)

## 5. SWE-agent（Princeton / Stanford；**已被官方降级为 legacy**）

- **定位**: 学术研究型 coding agent——「给一个 GitHub issue，用你选的 LM 自动尝试修复」，同时可用于进攻性安全与竞赛编程。**官方明确 "Made for research"**。

  - **维护状态（关键）**: README 顶部原文 "Most of our current development effort is on mini-swe-agent, which **has superseded SWE-agent**… Our general recommendation is to use mini-SWE-agent instead of SWE-agent going forward."；swebench.com 导航栏直接标注 **"SWE-agent (legacy)"**。**最新 release = v1.1.0 / 2025-05-22T16:11:39Z**，距观察日**约 16 个月无发版**。`pushed_at` 有误导：main 分支最后 commit 实为 **2026-07-16**，2026-09-21 那次 push 不在 main 上（SWE-agent / mini-swe-agent / SWE-ReX 三仓库同秒被 push，原因未核实）。[来源](https://raw.githubusercontent.com/SWE-agent/SWE-agent/main/README.md) [来源](https://api.github.com/repos/SWE-agent/SWE-agent/releases/latest) [来源](https://api.github.com/repos/SWE-agent/SWE-agent/commits?per_page=5) [来源](https://www.swebench.com/)

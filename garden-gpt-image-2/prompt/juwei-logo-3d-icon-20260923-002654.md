## 怎么用

任选其一，把上面整段 JSON 作为 prompt 传入：

- **ChatGPT / DALL·E / Sora**：直接粘贴（图像模型能读结构化 JSON）
- **Midjourney**：建议拍平成一句话，去掉大括号，例如
  `skeuomorphic 3D app icon, rounded square tile, warm orange diagonal gradient #ea580c to #fbbf24, white solid mark fusing a vertical film strip with 3 rounded sprocket-hole cutouts into a right-pointing play triangle, soft studio light, soft drop shadow, dark charcoal background, no text --ar 1:1`
- **自己后端 / 第三方 GPT Image 2 网关**：`POST /images/generations`，`size=1024x1024`，`quality=high`

## 注意

- 图像模型**画不准精确几何**：3 个齿孔的数量、朝向、镂空关系经常出错。**量产请用矢量母版**（`docs/brand/juwei-logo.svg`），这版 3D 图只适合做宣传视觉。
- 生成后建议按 `docs/brand/README.md` 的规范逐条核对（尤其"齿孔是镂空"和"无文字"）。
